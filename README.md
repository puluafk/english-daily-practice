# English Daily Practice

Interactive website for daily English practice with three levels (Beginner, Intermediate, Advanced).

## Features

- **3 levels**: A1–A2, B1–B2, C1–C2
- **Exercise types**: Vocabulary, Grammar, Reading, Mixed Quiz
- **Daily Challenge** to keep your streak
- Instant feedback + explanations
- XP system & progress tracking (saved in browser)
- Colorful, responsive design
- Works offline after first load

## How to use

1. Open the site
2. Choose your level
3. Pick an exercise type or start the Daily Challenge
4. Answer questions and check your score

## Deploy

This is a static site. Deploy to Vercel, Netlify, or any static host.

```bash
# Local preview
npx serve .
```

## Tech

Pure HTML + CSS + JavaScript. No build step required.
